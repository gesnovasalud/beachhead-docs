# Diagnósticos

## Descripción General
El módulo Diagnósticos permite consultar el catálogo clínico utilizado en los registros de atención y en la documentación clínica.

## Visualización del Listado
La tabla permite buscar y ordenar por **Código** y **Nombre**. También muestra indicadores para identificar si el diagnóstico corresponde a **Epicrisis**, **ENO**, **GES** u **Oncológico**.

Cada indicador permite filtrar los resultados por **Sí**, **No** o **Todos**. Además, se pueden consultar los registros eliminados lógicamente mediante el filtro correspondiente.

## Datos del Diagnóstico
Cada diagnóstico cuenta con código, nombre, descripción e indicadores de clasificación para los procesos que utilizan el catálogo.

## Consideraciones
En la versión actual, este módulo solo permite consultar el listado. La creación y edición de diagnósticos no están habilitadas desde esta pantalla.
