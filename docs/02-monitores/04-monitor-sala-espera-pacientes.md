# Monitor Sala de Espera Pacientes

## Descripción General
El Monitor Sala de Espera Pacientes presenta una vista resumida del estado de cada paciente mediante tarjetas, para facilitar el seguimiento del proceso quirúrgico.

## Información Mostrada
Cada tarjeta incluye:

- **Iniciales del paciente**, en lugar del nombre completo.
- **Pabellón** asociado.
- **Estado del paciente**, como **En Pabellón, En Cirugía ó Salida de Quirófano**.
- **Fecha y hora** asociadas al estado mostrado.

## Visualización
Las tarjetas permiten identificar de forma rápida el pabellón y el estado informado para cada paciente. A diferencia del [Monitor Sala de Espera](02-monitor-sala-espera.md), esta vista resume la información sin mostrar el cirujano ni el detalle de los horarios de la intervención.
